## AI 활용 고지

이 프로젝트에서는 AI 서비스로 **Claude (Anthropic)** 를 사용했습니다.

### AI를 활용한 범위

| 영역 | 활용 내용 |
| --- | --- |
| 문제 탐색과 사례 조사 | 문제를 정리하고 관련 사례를 찾는 과정에서 도움을 받음 |
| 데이터 소스 확인 | 활용 가능한 데이터 소스를 확인하는 데 도움을 받음 |
| 분석 코드 작성 보조 | 분석 코드의 초안 작성과 수정에 도움을 받음 |
| 결과 해석 보조 | 분석 결과를 해석하는 과정에서 의견을 참고함 |

### 직접 수행한 부분

| 영역 | 직접 한 내용 |
| --- | --- |
| 데이터 내려받기 | 데이터를 직접 내려받아 사용함 |
| 지표 정의 확정 | 분석에 쓴 지표의 정의를 직접 결정함 |
| 결과 검증 | 분석 결과를 직접 확인하고 검증함 |
| 제안의 취사선택 | AI가 제안한 내용 중 채택할 것과 버릴 것을 직접 골랐음 |
