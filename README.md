# PublicTransportation_Analysis

버스 노선이 줄면 병원으로 가는 직통을 잃는 읍면은 어디인가
    : 공주·고창·김천 52개 읍면동의 병원 연결 취약성 분석

## 개요

- **목적:** 정류장이 가까운 읍면도 병원으로 가는 직통이 한두 번의 운행에 걸려 있을 수 있다는 점을 찾는다. 노선이 줄기 전에 이를 확인해 대체수단을 먼저 배치할 근거를 만드는 것이 목적이다.
- **데이터 소스:** 모두 공공데이터이며 수집 시점과 이용 조건은 각 제공기관 기준을 따른다.
  - 행정안전부 주민등록 인구(2026.9.30)
  - 국토교통부 전국 버스정류장 위치정보(2025.10.31)
  - 공주시 버스 노선 정보 API, 국토교통부 TAGO 버스노선정보 API(김천시·고창군)
  - 지방행정인허가 건강_병원
  - 통계청 센서스 행정동 경계(2025.6.30)와 행정동 코드표 [확인: 코드표 제공기관·URL]
- **주요 지표:**
  - 병원 정류장: 병원 300m 이내 정류장(주 기준, 500m는 민감도 분석)
  - 연결 수준: 직통 / 환승 1회 / 불가(데이터 미확인). 직통은 정류장 순서를 반영해 병원 정류장을 지난 뒤 구간은 제외한다. 환승은 방향을 반영하지 않아 낙관적 상한이다.
  - 운행 단위: 개별 운행(route_id). 노선번호 단위로 합치지 않는다.
  - 감축 시나리오: 시군별 운행의 10·20·30%를 무작위로 1,000번 제거해 읍면별로 병원 직통이 없어질 확률을 구한다.
- **결과 요약:**
  - 52개 읍면동 중 병원 직통 45곳, 환승 필요 6곳(공주 탄천, 김천 구성·지례·부항·대덕·증산), 데이터 미확인 1곳(김천 아포읍).
  - 직통이 운행 하나뿐인 읍면이 3곳(공주 반포, 김천 조마·감천, 65세 이상 3,570명)이다. 운행의 20%가 줄면 직통을 잃을 확률은 반포 21%, 조마·감천 19%였다.
  - 정류장 거리와 병원 거리의 상관은 0.40으로 약했고, 정류장이 가까운 탄천면(6m)도 병원까지 15.7km였다.

## 한계

- 거리는 도로 거리가 아닌 직선거리이고 읍면의 대표점·경계 안 정류장을 기준으로 한다.
- 병원 반경 300m는 가정이다. 500m로 넓히면 김천 읍면 대부분이 터미널행 직통을 갖게 되어 결과가 달라진다.
- 환승 판정은 방향을 반영하지 않아 낙관적 상한이다. 돌아오는 방향 운행은 수집 데이터에 없다.
- 운행 시각과 배차 간격을 반영하지 못했다. 직통 운행이 진료 시간에 맞는지는 판단하지 않았다.
- 몬테카를로는 운행을 무작위로 제거한 구조적 시나리오이며 실제 폐지를 예측하지 않는다.
- 대상은 3개 시군 52개 읍면동과 병원 6곳이다. 김천 아포읍은 노선 데이터에서 정류장이 확인되지 않아 유형 분류에서 제외했다.
